# recipes

My personal recipe collection, published with GitHub Pages / Jekyll.

Live at: https://saakshimore.github.io/recipes/

## Adding a recipe

Add a new Markdown file to `_recipes/`, e.g. `_recipes/my-dish.md`:

```markdown
---
title: My Dish
tags: [tag1, tag2]
time: 30 min
servings: "4"
ingredients:
  - ingredient one
  - ingredient two
notes: Optional freeform note.
---

1. Step one.
2. Step two.
```

Push to `main` and GitHub Pages rebuilds the site automatically.
